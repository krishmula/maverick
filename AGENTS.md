# Maverick

## Glossary

**Mav**:
The planning assistant inside Maverick. The user tells it what to remember or plan, and it proposes TickTick tasks and calendar blocks for the user to confirm.

**Profile**:
One connected Google account with a name the user picks, such as Work or School. Maverick connects at most 5.
_Avoid_: Google account (when the user-named profile is meant)

**Block**:
Time set aside on the calendar to work on something, which Mav proposes and the user confirms.
_Avoid_: event (for a block Mav adds)
