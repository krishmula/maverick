# Maverick

## Glossary

**Mav**:
The planning assistant inside Maverick. The user tells it what to remember or plan, and it proposes TickTick tasks and calendar blocks for the user to confirm.

**Profile**:
One connected Google account with a name the user picks, such as Work or School. Maverick connects at most 5.
_Avoid_: Google account (when the user-named profile is meant)

**Block**:
Time set aside on the calendar to work on something, which Mav proposes and the user confirms.
_Avoid_: event (for a block Mav adds)

**Jobs tab**:
The view where the user approves or skips postings, sees who to reach at each posting's company, and sees the applications sent. Approving a posting queues its form to be filled in a batch.
_Avoid_: approvals, decision board, jobs list

**Posts tab**:
The view for hiring posts found on LinkedIn and the notes drafted to their posters.
_Avoid_: outreach tab

**Auto-apply**:
The switch in Connections that lets Maverick approve each posting scored 75 or more and send a LinkedIn draft to the best two people at it, without the user's review. While it is off, the user approves each posting.
_Avoid_: auto-reach
